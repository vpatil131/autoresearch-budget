# Security reporting

For suspected credential leakage, sandbox isolation failures, or access to hidden verifier material during solving, contact the maintainer privately at dev@vrpatil.com. Include the affected version, a minimal reproduction, and redacted logs. Do not include API keys or private benchmark solutions in a public issue.

This experimental harness executes coding-agent commands inside task environments. Keep inference credentials in the host environment or an ignored environment file, and preserve the documented separation between solving evidence and post-submission grading. Reports can reference private experiment evidence; review exported bundles before sharing them.
